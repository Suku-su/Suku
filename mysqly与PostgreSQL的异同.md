 mysql与postgresql

+ 索引

| mysql                                                        | postgresql                                                   |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 聚簇索引：按照主键查询效率较高，主键存储数据，非使用的是二级索引，需要回表 | 所有的索引都是二级索引，数据存放在u堆表里面，索引里面存放的指向堆表的数据的指针， |
| 主键索引与数据不分离，索引保持一致存在差异                   | 索引与数据分离，索引保持一致不存在差异                       |
| 随机插入数据的时候可能会造成b+树分页                         | 随机插入数据可以直接插在堆表的尾部，不能分页、排序操作等     |
